# GitHub Copilot Desktop 汉化工具（使用说明）

> 本工具用于把 **GitHub Copilot **（Windows 桌面版）界面汉化为简体中文。
> 汉化是对 `github.exe` 内部资源做本地替换，**不联网、不改账号、不影响登录**。

---

## 〇、使用前必读（重要）

1. 汉化前请**完全退出 GitHub Copilot**（包括右下角托盘图标，右键 → 退出），否则文件被占用、无法写入。
2. 汉化约需 **5 分钟**，请耐心等待，期间不要关闭窗口。
3. 汉化后 exe 数字签名可能会导致失效，首次打开 Windows 可能会弹 SmartScreen，点「仍要运行」即可（正常现象）。

---

## 一、需要哪些依赖（提前了解）

本工具依赖两个东西：

| 依赖 | 说明 |

|---|---|---|

| **Python 3.10+** | 运行汉化脚本的解释器 | 必需 |

| **brotli** | Python 的解压/压缩库 | 必需（缺了脚本会秒退报错） |

> 这两个依赖**本工具不会自动帮你判断有没有装好**，需要你先按下面的步骤自行确认。

---

## 二、检查并安装依赖

### 第 1 步：双击「安装依赖.bat」需要以管理员身份运行

双击工具文件夹里的 **`安装依赖.bat`**，它会自动：
1. 检查 Python 是否 ≥ 3.10
2. 检查 Python 是否在 PATH 里
3. 检查 brotli 是否已安装（缺了就自动 `pip install`，国内优先走清华镜像）

**如果最后显示三项全部 `[OK]`、提示「汉化依赖配置完成」**，说明依赖就绪，跳到「三、开始汉化」。

### 第 2 步：如果「安装依赖.bat」没生效 / 报错

那就手动装这两个依赖：

**（1）安装 Python 3.10+**
- 到 https://www.python.org/downloads/ 下载安装
- 安装时**务必勾选「Add Python to PATH」**

**（2）安装 brotli**
装好 Python 后，打开「命令提示符」（按 Win+R，输入 `cmd` 回车），输入：
```
pip install brotli
```
看到 `Successfully installed brotli-...` 即成功。

装完后再回到「安装依赖.bat」跑一次确认，三项全 OK 再继续。

---


### 第 1 步：找到你的 GitHub Copilot 真实安装路径

1. **右键桌面的 GitHub Copilot 图标** → 点「**属性**」
2. 切到「**快捷方式**」标签页
3. 在「**目标**」那一栏，**复制双引号内的路径**（形如 `C:\你的目录\GitHub Copilot\github.exe`）

### 第 2 步：在 hanhua_bin.py 里改路径

1. 在下载的汉化工具文件夹里，找到 **`hanhua_bin.py`**
2. **右键它 → 打开方式 → 记事本**（或用记事本打开）
3. 在文件里找到这一行：
   ```
   DEFAULT_EXE = r'D:\Program Files (x86)\GitHub Copilot\github.exe'
   ```
4. 把 `D:\Program Files (x86)\GitHub Copilot\github.exe` 这个路径，**替换成你第 1 步复制的真实路径**
   （注意：路径里的反斜杠 `\` 保持原样，不要删）
5. 保存文件（Ctrl+S），关掉记事本

改完后再双击 `汉化工具.bat` 重新汉化即可。

---


## 三、开始汉化

双击 **`汉化工具.bat`**需要以管理员身份运行 → 输入 `1` 回车。

正常会看到类似下面的过程（约 5 分钟）：
```
[+] 找到 525 个待处理 JS bundle
[+] 加载词典 6679 条
  [ 63] '/assets/router-...js': +9467 处 ...
  ...
[+] 共修改 30 个 bundle, 累计替换 11364 处
[+] 汉化完成！已写入 ...
```

看到「汉化完成」后，重启 GitHub Copilot 即可看到中文界面。

---

## 四、如果提示「未找到 github.exe」/ 路径不对，如何修改

汉化工具默认按常见路径自动定位 `github.exe`，但如果你的安装位置**不是默认路径**，需要手动改一下。


## 五、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 双击 bat「秒出 Done」但没汉化 | 依赖没装好（brotli 缺失），先跑「安装依赖.bat」 |
| 提示「Python 缺少 brotli 依赖」 | 跑「安装依赖.bat」，或手动 `pip install brotli` |
| 提示「未找到 github.exe」 | 按「四」修改 hanhua_bin.py 里的路径 |
| 汉化后打开还是英文 | 确认已完全退出 Copilot 再汉化；部分文案是服务端下发的，本地改不到（属正常） |
| 想还原英文 | 用备份文件 `github.exe.原版.bak`（或安装目录的 `github.exe.bak`）覆盖回安装目录 |
